# pptskills · PPT视觉专家开源基础版

让 AI 做 PPT 时，先把内容讲清楚，再把页面排清楚。

这是一套面向中文汇报、产品介绍和培训的 Codex 技能，提供内容梳理、标题层级、基础配色、图文排版与交付检查方法。免费、免激活，源码可读，按 MIT 许可证开放。

它是给 AI 使用的工作方法，**不是独立的 PPT 生成软件**。制作 PPTX 依赖运行环境已有的模型和文件制作工具；模型或第三方服务可能有自己的费用。本项目不承诺所有环境都能直接生成文件。

## 能帮你做什么

- 将一段文字组织成逐页讲述的内容。
- 优化文字密集页面的分组、字号与留白。
- 统一标题、正文、配色和图文比例。
- 在环境支持时生成可编辑 PPTX，并按实际可用工具检查画面。

本仓库不包含任何公司的模板、Logo、产品图库、商业字体、内部案例、订单或密钥。需要特定品牌风格时，请提供自己的规范和有权使用的素材。

## 安装

下载仓库 ZIP 并解压，把文件夹交给 Codex，发送：

> 请读取 README，运行 install.py，安装包内的 ppt-visual-expert-lite 技能。如已存在同名技能，先核对，不直接覆盖。

安装脚本只复制本地文件，不联网，不需要管理员权限；需要环境中有 Python 3。

在仓库目录运行：

```bash
python3 install.py
```

Windows 可使用 `py -3 install.py`。可通过 `--dest` 指定技能父目录；相同内容重复运行不做修改，已有不同内容的同名技能会停止安装。

也可以手动将 `skills/ppt-visual-expert-lite` 整个文件夹复制到 `~/.codex/skills/`。Windows 对应用户目录下的 `.codex/skills/`。如果配置了 `CODEX_HOME`，则放入该目录的 `skills/`。安装后新开 Codex 对话；若未发现技能，再重启 Codex。
